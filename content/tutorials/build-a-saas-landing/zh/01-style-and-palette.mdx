落地页就是一屏完成一件事的页面。最难的部分不是写 Prompt，是**在开始写
Prompt 之前，先想清楚这一页应该是什么感觉**。这一步你要是跳过，模型
就会拿它的「家用味」把空白填满，于是你又得到了一个紫色渐变 Hero。

这一步**不会生成任何东西**。这就是无聊的、决定后面四步走不走得动的那
10 分钟。

## 为什么 AI 一个人做不好这件事

你让 Claude（或者任何模型）「为我的 SaaS 落地页挑个风格」，它干的事
基本上和一个没有品味的初级设计师一样：套上最近两年最常见的那几个模板。
当你**手上什么都没有**的时候，这样做也行。但**你才是知道自己品牌的那
个人**，这件事不该让模型做。

Skill 之所以预置了 **50 种风格** 和 **21 套配色**，就是因为这个选择
应该是**从精选集合里挑一个**，不是「vibes 插值」出来的。

## 写 Prompt 之前先决定 3 件事

<Checklist
  storageKey="saas-landing-step-01"
  title="生成任何东西之前"
  items={[
    { id: 'audience', label: '这一页是给谁看的？（一句话，不是用户画像文档）' },
    { id: 'feeling', label: '访客进来 2 秒内应该有什么感觉？（一个形容词）' },
    { id: 'style', label: '从 50 种风格里挑哪个？写下名字。' },
    { id: 'palette', label: '从 21 套配色里挑哪个？写下名字。' },
    { id: 'forbidden', label: '明确不想要的三样东西。' }
  ]}
/>

这清单看着简单，真填一遍才知道有多难。最难的是「不想要」那一行——
这是你**在认真承诺这一页不是什么样**。

## 怎么挑风格

直接用 database 搜，不要猜：

<CodeBlock
  title="浏览风格"
  language="bash"
  code={`# 在 Claude Code 里
+style list

# 也可以按 tag 过滤
+style list --tag editorial --tag asymmetric`}
/>

挑**一个**，不是三个。精选集合存在的意义就是「判断品味」这件难事别
人替你做过了——你的工作是**承诺一个选择**，不是把它们求平均。

<Callout tone="info" title="如果实在选不出来，这是个不错的默认值">
  B2B SaaS 落地页，「Editorial Brutalist」+「Slate Ink」是一对很
  耐用的开箱即用组合：衬线显示字体的标题、大量留白、一个克制的主色、
  没有任何装饰性渐变。哪怕里面还没填内容，看着也已经像是有人做过决定。
</Callout>

## 怎么挑配色

配色决定是**风格决定的下游**。有些风格有推荐配色，直接用。如果你挑
的风格没指定，那就挑一套主色和你上面写的那个形容词对得上的。

<CodeBlock
  title="浏览配色"
  language="bash"
  code={`+palette list --style editorial-brutalist
+palette show slate-ink`}
/>

## 这一步结束的时候你应该有什么

打开一个临时文件（或者一张便签）写下来：

```
受众：____
感觉：____
风格：____
配色：____
不要：____、____、____
```

这 5 行就是第 02 步的输入。我们这一步**没有生成任何 UI**，是有意的。
**能扛得住真实用户的页面，一定是先做了风格决定再做版式决定的**——
而大多数团队顺序搞反了。

## 下一步

第 02 步我们会拿这 5 行去写**一个真正的 Prompt**，目标是产出一个
**你愿意留着不重做的** Hero。我们不会让模型「设计一个落地页」。
我们会让它**把你已经做好的决定执行出来**。
