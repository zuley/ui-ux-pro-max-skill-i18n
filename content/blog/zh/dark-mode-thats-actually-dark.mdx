你让 Claude「把这一页换成暗色模式」，它给你的东西从技术上讲**是**暗
的——`bg-gray-900`、`text-gray-300`、所有图标都变成了灰扑扑的版本——
但是页面没了骨头。对比度发飘，主色像泥巴，整个东西看着就像**亮色
模式套了一身黑衣服**，而不是为暗色场景设计出来的。

这是 AI slop 里最常见的形态之一，原因很具体：**模型把暗色模式当成
了亮色主题的一次变换**。同样的层级、同样的主色、同样的阴影配方，
只是反过来。可这不是好的暗色模式的样子，所以结果总是不对劲。

## 「暗色模式是一套独立的设计」是什么意思

真正的暗色主题不是「亮色主题但 `--bg: #1a1a1a`」。它是一套**关于
对比、深度、主色的平行决定**。这套思路最经典的版本是 Material 3 的
「按表面亮度区分层级」——**越往前的表面颜色越亮**，因为在黑底上你
没法用阴影制造层级。

如果你 AI 生成的暗色模式还在用 `box-shadow` 把卡片浮起来，那就是
最明显的破绽。**阴影在暗里不存在，光才存在。**

<Callout tone="info" title="一个能纠正过来的心理模型">
  亮色模式里，**深度来自阴影**。暗色模式里，**深度来自亮度**。
  暗背景上一张「凸起」的卡片，应该**比底面更亮**，不是用一圈光晕
  浮上去。
</Callout>

## 一眼能看出是「AI 暗色」而不是暗色的 4 个特征

模型给你扔回来一张截图，扫一遍找这 4 样东西。每一样都是指纹：

1. **纯黑背景**（`#000` 或 `#0a0a0a`）。真正的暗色主题大概在
   `#1a1a1a`–`#1f2937` 这一带，因为 OLED 级别的纯黑会把旁边所有
   颜色都吸干。如果你界面里有蓝调或者暖调，背景要带一点同样的倾向。

2. **亮色模式的主色直接拖过来。** 在白底上很提神的靛蓝，到黑底上
   往往变成**沉默的海军蓝泥**。暗色模式的主色基本上都需要
   **更亮、更不饱和**。

3. **正文用 `#fff` 或 `gray-100`。** 纯白在黑底上会刺眼，会有「嗡嗡」
   的视觉震动。成熟产品的暗色模式正文是 `gray-200` 或者
   `rgba(255,255,255,0.87)` 这个量级，文字坐**在**页面上，而不是
   浮在页面前面。

4. **边框用透明度而不是带色调的灰。** `border-white/10` 就是 AI
   的指纹。它能用，但全网每一页都是这个样子。一个用 `rgb(38 43 56)`
   写出来的边框，看着像有人**做过决定**。

## 真正管用的 Prompt 模板

修这件事的关键是**不要再让模型「做暗色版本」**。要让它**像给一个
没见过亮色版本的设计师做 brief 那样**去设计一套暗色：

<CodeBlock
  title="一套真正暗色主题的 Prompt 骨架"
  language="text"
  code={`为这一页设计一套暗色主题。不要从亮色主题开始派生。

背景：#14161a（中性偏暖的暗色，不是纯黑）
表面（卡片、面板）：#1c1f24（**比背景更亮**——这是暗色里的层级表达）
正文：rgba(255, 255, 255, 0.86)
弱化文本：rgba(255, 255, 255, 0.56)
主色：把亮色模式的 #4f46e5 沿亮度轴上移到 #818cf8。同色相、更高
  明度——**更亮**，不是更蓝。
边框：rgb(38 43 56)。不要用白色加透明度。
凸起元素不要用 box-shadow，改用更亮的表面色。

整套主题应该看起来是**为暗色设计出来的**，不是从亮色复制过来的。
如果某个东西看着像是它亮色版本的反色，就改掉。`}
/>

最后一段是最干活的一段。**显式允许模型「偏离亮色版本」**，是阻止
它做机械反色的关键。

## 一个能套在任何暗色模式上的检查清单

拿到模型给的东西之后，发布前花 15 秒：

<Checklist
  storageKey="blog-dark-mode-test"
  title="暗色模式 15 秒检查"
  items={[
    { id: 'bg', label: '背景不是纯黑？（#1a 那一带，不是 #000）' },
    { id: 'accent', label: '主色比它亮色模式的版本更亮？' },
    { id: 'depth', label: '凸起的表面是更亮，而不是用阴影浮上去的？' },
    { id: 'body', label: '正文是带一点灰的白，不是纯 #fff？' },
    { id: 'border', label: '分隔线是带色的灰，不是 white-with-opacity？' }
  ]}
/>

5 条里答不出 4 个 yes，那就是「AI 暗色」，不是暗色。

## 更深一层的规律

和第一篇文章里讲的反 AI slop 是同一条原则：**暗色模式是一个决定，
不是一次变换。** 你一旦把它当作「把颜色翻一下」的同一件东西，那
个让好的暗色主题值得做的「独立性格」就已经丢了。

模型乐意做反色，只要你让它做反色。**直接让它做「设计」，并且明确
告诉它暗色主题有自己的主张**。
