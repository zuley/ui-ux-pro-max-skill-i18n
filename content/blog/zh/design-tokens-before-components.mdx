生成的 Tailwind 有一种和页面好不好看毫无关系的标志性失败。要一个落地
页，拿到一个漂亮的——然后 `#6D28D9` 出现在十四个 class 串里，
`#6C28D9`（注意模型在 212 行打错的那个字）又出现在两个里，同一套间距
节奏在三个相邻 section 里分别写成 `mt-7`、`mt-8` 和 `mt-[30px]`。

页面没事。*系统*是死胎。第一次你说「把强调色调暖一点」，你就在对一堆
要逐个考古发掘的十六进制变体做全局替换。

这不是模型质量问题，是**顺序**问题。模型先写组件、边写边上色，就像
初级开发直接往画布上涂。解法也和带初级开发一样：先 token，后组件，
并且从此不许再出现裸值。

## 两个 Prompt，不是一个

错误在于一口气把页面和系统一起要。拆开。第一个 Prompt *只*产出
token 层——而且它很短：

<CodeBlock
  title="Prompt 1——只要 token"
  language="text"
  code={`把这个项目的设计 token 定义成 globals.css 里的 CSS 自定义属性，
加上 Tailwind 主题映射。其他什么都不要——不要组件，不要页面。

# Decisions（已锁定）
配色：<你的 5 个颜色，带色值和角色>
字体：<标题字体 / 正文字体，字阶：14, 16, 20, 28, 40, 56>
间距节奏：4px 基准；section 留白桌面 96px / 移动端 64px
圆角：控件 8px，卡片 16px。阴影：恰好两档海拔。

# Rules
- token 按「角色」命名（--color-accent、--color-ink-secondary），
  永远不按「值」命名（--purple-600、--gray-light）。
- 每个 token 配一行注释：它允许被用在哪里。
- 如果两个 token 会装同一个值，合并它们并注明两个角色。`}
/>

按角色命名是日后真正交房租的那一行。强调色改成青色的那天，
`--purple-600` 就成了谎言——而拿到值命名的模型，会面不改色地定义
`--purple-600: #14b8a6`，绝不主动改名。

## 然后是围栏，进每一个组件 Prompt

第二个 Prompt——以及此后的每一个 Prompt，永远——都带上这一个块：

<CodeBlock
  title="禁裸值围栏"
  language="text"
  code={`# Token 纪律（没有商量余地）
- 标记里零裸值：不许十六进制、不许 rgb()、不许 mt-[30px]
  或 text-[#333] 这类任意值。
- 颜色、间距、圆角、阴影：只能走 globals.css 里的 token。
- 如果设计需要一个没有 token 提供的值，停下来说出来——
  提议新 token，等批准。不许临场编一个。
- 单为这条规则产生的 diff 应该是空的。`}
/>

第三条才是真正干活的。没有逃生通道，模型会把规则当软的，token 一缺
就临场编出 `bg-[#f8f7ff]`；有了「停下来提议」这条路，缺失的 token 会
以*问题*的形式浮出水面，而不是变成无声的债。每页你大概会收到两三个
这样的问题，每一个都是你差点儿不知不觉做掉的设计决策。

## 周五测试

怎么知道做对了——周末前试这三个改动，每一个都应该是一行的事：

- 强调色调暖 → 改 `--color-accent`，完事。
- 收紧所有卡片的内边距 → 改一个间距 token，完事。
- 换标题字体 → 改字体 token 和它的回退栈，完事。

任何一条把你领进了组件文件，围栏就漏了。grep 会告诉你漏在哪：在组件
里搜 `#`、`rgb(` 和 `-[`。每一处命中要么是缺失的 token（提拔它），
要么是模型的即兴发挥（替换它）。围好栏的代码库里这条 grep 一无所获
——这也是你能加的最便宜的 CI 检查。

<Callout tone="warn" title="任意值是后门">
  Tailwind 的方括号语法是模型最爱的走私通道——为了贴合它想象中的
  截图来一个 `w-[417px]`，因为写色值比查 token 名快就来一个
  `text-[#4b5563]`。围好栏的项目把方括号一律当代码异味，唯一例外
  是真正一次性的几何尺寸——而「真正一次性」的标准是：你能在注释里
  写出为什么。
</Callout>

## 为什么有了 AI 这事更重要，而不是更不重要

手写代码的不一致要几个月才漂移出来；模型一个下午就能产出全部烂摊子，
带着完美的自信，速度是你审查速度的两倍。token 层是*唯一*一个用一次
决策约束几千行生成代码的杠杆点——而这正是你和生成器之间想要的分工：
你拥有十个决策，它拥有一万次击键。

先 token，围栏永远在。产出的页面和一把梭版本看起来一模一样——整整
一个星期，直到第一个改动需求到来。然后它们就是两个不同的产品了。
